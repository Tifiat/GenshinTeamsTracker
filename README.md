# GenshinTeamsTracker

Настольное приложение для ведения ростера Genshin Impact, сборки команд и
планирования боёв в Витой Бездне. Репозиторий содержит исходный код приложения
на PySide6 и интеграцию с GCSim для симуляций и экспериментальной оптимизации.

## Возможности

- Каталог персонажей и оружия, фильтры и управление выбранной командой.
- Просмотр артефактов и экипировки, импорт данных аккаунта HoYoLAB.
- Подготовка команд и расчёт комнат Витой Бездны, сохранение запусков и History.
- Интеграция с GCSim для симуляций и оптимизатора с режимами Selected Sets,
  All Sets и Theory.
- Разделы PvP для локальных турнирных колод и матчей.

Часть экранов и сценариев находится в разработке или требует дополнительной
проверки в самом приложении. В частности, AppShell пока отдельный опытный
интерфейс, а оптимизатор и PvP не следует считать полностью принятыми для всех
команд и пользовательских сценариев.

## Запуск в Windows

Для текущего проекта используется Python 3.11 и зависимости из
[`requirements.txt`](requirements.txt): PySide6, Playwright и Pillow.

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

`main.py` запускает legacy-интерфейс. Разрабатываемый AppShell запускается
отдельно командой `.venv\Scripts\python.exe -m ui.app_shell_smoke`; это не
заменяет основной запуск. На другой ОС запуск отдельно не подтверждён.

## Технологии

- Python, PySide6 и SQLite для настольного интерфейса и локальных данных.
- Go для нативного оптимизатора GCSim.
- Playwright и Pillow для отдельных сценариев импорта и работы с графикой.

Основные области кода: `ui/` — интерфейс, `run_workspace/` — команды,
симуляции и рабочие данные, `hoyolab_export/` — импорт и каталоги,
`native/gcsim_optimizer/` — Go-оптимизатор, `tests/` — проверки.

## Ближайшие задачи

Срез продуктовых задач на **28 октября 2026 года**. Это обзор для посетителя
репозитория, а не отдельная очередь работ; оперативный порядок хранится в
проектной документации.

- Завершить проверку и исправления оптимизатора Theory на реальных командах;
  текущий этап экспериментальный и не подтверждает полную сходимость поиска.
- Проверить основные сценарии History в приложении: сохранение, открытие,
  фильтры, отображение и экспорт.
- Завершить проверку импорта HoYoLAB и переключения локальных профилей на
  сохранённых данных.
- Проверить PvP-сценарии с изолированным вторым профилем и завершить
  недостающие правила турниров и сохранение матчей.
- Подготовить распространяемую сборку без среды разработки и проверить её
  размер, установку и расположение пользовательских данных.

## Данные и статус

Приложение работает с локальными данными аккаунта и пользовательскими
профилями. Не добавляйте в публичные коммиты реальные выгрузки HoYoLAB,
учётные данные, локальные базы профилей или отладочные дампы. Статус функций
различается: наличие исходного кода не означает завершённую проверку
пользовательского интерфейса или поддержку всех игровых сценариев.
