## Health capture rationale and regression ownership

`compileMaxHPRead` and base-snapshot indexing previously used `Provider.Key`:
executing Furina code could be mistaken for a read owned by Bennett. Typed
`OwnerIndex` now owns the artifact coordinate; absent/invalid owners freeze
with a diagnostic. Synthetic fixtures provide the real emitted receiver field,
not weaker validation. The whole compact package passes.

The subsequent frame93 loss was a saved local amount: the typed receiver's
MaxHP had been collapsed before the health handler. The source observer now
captures the original expression where it is computed, not later at the call.
Eligible direct fields and single-use locals retain arithmetic and typed refs;
ambiguous aliases/writes/escapes remain conservative. No game formula, actor
name or coefficient is copied. Tests cover renamed receivers, loop scope,
single getter position, original disabled path, rejecting unsafe locals and
foreign packages, full-tree generation, and the portable13-node real scalar.

The permanent receipt's `health_owner_repair` contains the passing scalar and
five explicit schedule witnesses. State comparison matches kind/frame/provider/
owner/source/operation/key and occurrence only when group sizes agree, rather
than comparing shifting event IDs. Unmatched events are not arithmetic errors;
this diagnostic matching is not a general proof of event identity. Support
export belongs only to the experimental compiler overlay, not the product API
or engine patch. All final response/parity/search evidence uses built audit5.
