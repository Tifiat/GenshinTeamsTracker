The former `engine_delta.patch` is removed after consolidation into the single
production patch, official installation, installed parity and the user's
button feedback. Its source/tests remain in the production patch; neutral
`select_lt` support remains in the paired consumer. Do not recreate a second
production stack. `export_pending.py` is an explicit future audit utility, not
a startup/build dependency. Current identities and acceptance belong to the
checkpoint. The43-point audit, old-winner replay and copied-account search use
audit5. Five health controls retain diagnosed schedule boundaries; the later
user Chasca run is a functional check, not broader formula proof.

Utilities require the project venv and existing isolated evidence; none fetch
private data, change equipment, activate engines or start the UI:

- `export_pending.py`: mechanical reviewed-source delta, paths allowlisted by
  the consolidated candidate patch. Refuses unsafe paths/invalid JSON/EOF joins.
- `recheck_ordered.py`: bounded n1 stat probes. **Append**, never prepend, an
  add-stats command. Prepending can change GCSIM character initialization order.
  Reuse baselines only from the same engine/build/config.
- `run_matrix.py`: actual native reference/dense scorers via a temporary Go
  overlay. Inspect `response.json`; runner success is NOT an acceptance pass.
- `run_parity.py`: ordinary vs trace-enabled simulation, with generated build
  overlays correctly relocated from updater staging paths. Each hit/frame must
  match. No mocked gameplay arithmetic.
  Optional `--case` exports observed support graphs for narrow diagnosis;
  `--support-source` overlays only a reviewed compiler source, not gameplay or
  a product installation. `support_graph_probe.go` belongs only to this overlay.
- `export_samples.py`: prune actual graph ancestry; expected changed damage is
  copied from fresh engine captures, not calculated by the fixture generator.
- `export_health_sample.py`: one observed foreign HP-dependent scalar, wrapped
  as an explicitly artificial test channel to exercise the native scorer.
- `export_receipt.py`: dated local audit closeout projection; requires its
  explicitly named isolated evidence, not a general product command.

Public fixture rotations come from the eight official database links in the
receipt. Public gear/constellations are formula fixtures, not account search
results. The one full Selected run uses the already-approved copied Lauma 4p
account fixture. Native regressions need no engine or ignored raw files:
`go test ./internal/formula -run TestDependencyAuditResponses`.
